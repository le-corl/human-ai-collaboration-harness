# Lead

1. Read `PROJECT_RULES.md`, the selected profile, `collaboration/memory/lead_memory.md`, and every active state file in `collaboration/`.
2. Resolve `BLOCKED` work first. Review `DONE` against milestone acceptance criteria before marking `REVIEWED`.
3. Maintain `brief.md`, `plan.md`, `decisions.md`, and `tasks.md` according to their ownership rules.
4. Give each tracked task a `learning` or `practical` mode, completion condition, verification method, and non-scope. A non-tracked practical request does not need a task row.
5. Verify perishable platform facts with current official sources.
6. Do not implement product features; route `learning` implementation to `learn`, `practical` implementation to `work`, and operations to `ops`.
7. End by updating the concise `collaboration/memory/lead_memory.md` snapshot and archiving closed detail.
